# Keys and Buttons

## In the list

| Key | Action |
|---|---|
| **UP** / **DOWN** | Previous / next entry. Past the last entry the next page is loaded |
| **LEFT** / **RIGHT** | 12 entries up / down |
| **CHANNEL-** / **CHANNEL+** | One page down / up (a page is *Entries in list* long) |
| **OK** | Watch the selected programme |
| **RED** | Exit |
| **GREEN** | Channel selection |
| **YELLOW** | Download the selected programme |
| **BLUE** | Search. The keyboard starts with the selected entry's name |
| **MENU** | Menu: Download Manager, Settings, About |
| **INFO** | Programme information |
| **5** | Movie info (the raw fields) |
| **EXIT**, **HOME**, **TV** | Exit |

The colour buttons are labelled on screen: *Exit*, *Channels*, *Download*, *Search*.

Up and down also repeat while you hold the key.

## In the keyboard

The standard Enigma2 on-screen keyboard. **OK** or the keyboard's own confirm button starts the search, **EXIT** cancels. An
empty search shows the newest programmes of all channels.

## In the channel selection

Choose a channel with the cursor and **OK**. The first entry is *All channels*. **EXIT** cancels.

## While watching

Watching uses the same player as MovieCockpit, so the keys are the standard movie player keys:

| Key | Action |
|---|---|
| **OK** | Show or hide the info bar; while paused, resume |
| **PLAY** | Play / pause |
| **STOP**, **EXIT**, **POWER** | Stop and return to the list (or, with *Stop movie behaviour: Ask user*, a menu: Quit / Restart from the beginning / Continue playing) |
| **CHANNEL+** | Skip forward (smart jump) |
| **CHANNEL-** | Skip backward (smart jump) |
| **INFO** | The programme information |
| **FAST FORWARD**, **REWIND**, slow motion | Standard Enigma2 trick play |

Smart jump: the first press jumps 5 minutes. A second press of the same key forward jumps 1 minute. Each change of direction shortens the step
(1 minute, 30 seconds, 15 seconds). After 5 seconds without a key it starts over. This is described in more detail in the
[MovieCockpit playback page](../../MovieCockpit/docs/Playback.md#smart-jump).
